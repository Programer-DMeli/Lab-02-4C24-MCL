# lab-02-4C24-MCL
 Descripcion: Este proyecto consistio en conocer los comandos de git y las herramientas de gitHub para trabajar de manera colaborativa en proyectos

## Getting Started
Instrucciones para empezar el proyecto
- Primero se debe loguearse con una cuenta de github propio
- Segundo configurar con su usuario y gmail utilizando la terminal en git
- Tercero crear un nuevo repositorio en gitHub
- Cuarto inicializar git en tu carpeta en local
- Quinto utilizar los comandos de git (git add, git commit -m"First commit", git push ) para subir a remoto la carpeta de trabajo
